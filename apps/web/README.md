# @marquill/web

The Marquill product app: a Next.js 16 app with Clerk auth, the artifact library and composer, scheduling, and billing. It deploys to Vercel.

```bash
bun run dev   # http://localhost:3000; start the api (apps/api) for real data
```

Architecture, conventions, and environment variables are in [AGENTS.md](AGENTS.md). Repository-wide setup is in the [root README](../../README.md).
